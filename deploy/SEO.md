# SEO: что уже в коде и что делается руками

## Что уже сделано в коде

- `robots.txt` (`src/app/robots.ts`) — генерируется, закрывает `/admin/` и
  `/api/`, отдаёт ссылку на sitemap.
- `sitemap.xml` (`src/app/sitemap.ts`) — динамический: статические страницы,
  категории, бренды, товары, регионы, города, статьи блога.
- canonical, og:image, `ru-RU` — `src/lib/seo.ts`, подключено на всех страницах.
- schema.org JSON-LD — `src/lib/schema.ts` (Organization, Product,
  BreadcrumbList, FAQPage).
- `noindex` на служебных страницах и на фильтрах каталога (дубли).
- `X-Robots-Tag: noindex` на `/admin/*` заголовком (`next.config.mjs`).
- `llms.txt` — `public/llms.txt`, для ИИ-поисковиков.
- IndexNow — `src/lib/indexnow.ts`, пингует при изменении товара.
- Verification-теги Яндекса и Google — читаются из настроек админки, поле
  подставляется в `<head>` (`src/app/layout.tsx`).

Отдельного действия в коде это уже не требует.

## Что руками после деплоя

### 1. Открыть индексацию

В боевом `/etc/erfolg/erfolg.env`:

```
NEXT_PUBLIC_SEO_BLOCK_INDEX=false
NEXT_PUBLIC_FORMS_DISABLED=false
```

Это `NEXT_PUBLIC_*` — они вшиваются в бандл на сборке, поэтому после
изменения нужен не только restart, а пересборка: `bash deploy/deploy.sh`.

Проверить: `curl -s https://erfolgmt.ru/robots.txt` — не должно быть
`Disallow: /`; в исходнике страницы не должно быть `noindex`.

### 2. Яндекс.Вебмастер — https://webmaster.yandex.ru

1. Добавить сайт `https://erfolgmt.ru`.
2. Подтвердить права: способ «Мета-тег» → скопировать значение `content`
   → админка сайта, Настройки → «Я.Webmaster verification» → сохранить →
   вернуться в Вебмастер, нажать «Проверить».
3. Индексирование → Файлы Sitemap → добавить `https://erfolgmt.ru/sitemap.xml`.
4. Переобход страниц → добавить главную и основные разделы.
5. Указать регион сайта (Настройки → Региональность) — влияет на выдачу по
   геозависимым запросам.

### 3. Google Search Console — https://search.google.com/search-console

1. Добавить ресурс типа «Префикс URL»: `https://erfolgmt.ru`.
2. Подтвердить: «Тег HTML» → значение `content` → админка, Настройки →
   «Google verification» → сохранить → «Подтвердить».
3. Sitemaps → добавить `sitemap.xml`.
4. Проверка URL → главная → «Запросить индексирование».

### 4. Яндекс.Метрика

Счётчик создаётся на https://metrika.yandex.ru, ID (число) вписывается в
админке: Настройки → «Я.Метрика ID». Код подключается сам
(`src/components/seo/yandex-metrika.tsx`) и только при
`NEXT_PUBLIC_FORMS_DISABLED=false`.

### 5. IndexNow (необязательно, ускоряет переобход)

1. Сгенерировать ключ: `openssl rand -hex 16`.
2. `INDEXNOW_KEY=<ключ>` в env.
3. Создать `public/<ключ>.txt`, внутри — сам ключ, ничего больше.
4. Пересобрать и выложить.

### 6. Яндекс.Бизнес и карточки организации

Для медтехники с региональной привязкой карточка организации в
Яндекс.Бизнесе и Google Business Profile даёт видимость по гео-запросам.
Реквизиты — те же, что в `public/llms.txt` и в разделе «Контакты».

## Про сроки

Регистрация в вебмастерах — не «разрешение на индексацию», а канал связи и
ускорение. Робот нашёл бы сайт и сам, но с добавленным sitemap и запросом на
переобход всё идёт заметно быстрее.

Реальные сроки: Яндекс обычно даёт первые страницы в индексе через 1–3
недели, полный обход каталога — 1–2 месяца. Google — от нескольких дней до
2–3 недель. Позиции по конкурентным запросам растут месяцами, а не днями;
первые 2–4 недели после запуска выдача нестабильна, это нормально.

Проверять: в Вебмастере «Индексирование → Страницы в поиске», в GSC —
отчёт «Индексирование страниц».
